TRAINING CONFIGURATION
================================================================================

Model:           Qwen/Qwen2.5-7B (7B parameters)
Training Data:   7,540 chunks, 4.44M tokens
Eval Data:       16 chunks, 13K tokens
Epochs:          3

Learning Rate:   2e-5 (with warmup)

Estimated Time:

  A6000 (48GB):      12-14 hours
  A100-40GB (40GB):  10-12 hours
  A100-80GB (80GB):  6-8 hours

All settings customizable via command-line arguments or notebook config.

================================================================================

WHAT HAPPENS DURING TRAINING
================================================================================

Step 1: Load Data (1-2 minutes)
  - Loads 7,540 training chunks
  - Loads 16 eval chunks

Step 2: Initialize Model (2-3 minutes)
  - Downloads Qwen/Qwen2.5-7B (13GB)
  - Loads tokenizer
  - Initializes 7B parameter model

Step 3: Tokenize Datasets (3-5 minutes)
  - Converts text to token IDs
  - Handles padding and attention masks
  - Creates PyTorch datasets

Step 4: Training Loop (10-30 hours depending on GPU)
  - Epoch 1: 4-10 hours (slower due to compilation)
  - Epoch 2: 3-7 hours (faster)
  - Epoch 3: 3-7 hours

  What's saved:
  - Checkpoint every 200 steps
  - Validation every 100 steps
  - Best model selected by eval loss
  - TensorBoard metrics logged continuously

Step 5: Final Evaluation (1-2 minutes)
  - Runs full validation on eval set
  - Computes final metrics
  - Saves best model

Step 6: Generate Samples (1-2 minutes)
  - Tests inference on sample medical prompts
  - Verifies model works end-to-end

================================================================================

VERIFICATION AFTER TRAINING
================================================================================

Check Training Succeeded:
  python3 diagnose_training.py
  - Compares trained weights with base model
  - Verifies unfrozen layers were updated
  - Checks LM head was trained
  - Confirms parameter counts match

Review Training Metrics:
  tensorboard --logdir logs
  - View loss curves (should decrease smoothly)
  - Check learning rate scheduling
  - Verify GPU utilization (should be 70-90%)

Verify Model Loads:
  python3 << 'EOF'
  from transformers import AutoModelForCausalLM, AutoTokenizer
  model = AutoModelForCausalLM.from_pretrained("medical_qwen_cpt/best_model")
  tokenizer = AutoTokenizer.from_pretrained("medical_qwen_cpt/best_model")
  print("Model loaded successfully")
  EOF

Test Inference:
  python3 << 'EOF'
  from transformers import pipeline
  gen = pipeline("text-generation", model="medical_qwen_cpt/best_model")
  result = gen("The diagnosis of venous insufficiency", max_length=150)
  print(result[0]["generated_text"])
  EOF
