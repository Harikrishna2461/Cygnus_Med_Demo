================================================================================
DATA STRUCTURE
================================================================================

Each example contains:
1. source_document: Which PDF the example came from
2. page_or_section: Page number in the source document
3. instruction: Truncated text snippet (first 400 chars) describing the case
4. output: Full text of the clinical case description
5. shunt_type: CHIVA classification (1, 2, 2A, 2B, 2C, 3, 4, 5, 1+2, No shunt, Unknown)
6. ligation_strategy: Surgical/treatment approach described (if present)
7. clinical_notes: Flow patterns, hemodynamic observations, or clinical findings

================================================================================
EXTRACTION METHODOLOGY
================================================================================

Tools & Libraries Used:
- PyMuPDF (fitz): Primary PDF text extraction
- pdfplumber: Secondary extraction attempt for problematic PDFs
- pdf2image + Tesseract: OCR for image-based PDFs (attempted but requires poppler)
- Python regex: Pattern matching for classifications and flow patterns

Extraction Strategy:
1. Extracted complete text from all accessible PDFs
2. Segmented text into clinical case blocks
3. Applied CHIVA classification rules to identify shunt types
4. Extracted ligation strategies and clinical findings
5. Deduplicated examples to remove near-duplicates
6. Validated JSON structure and encoding

CHIVA Classification Rules Applied:
- EP N1→N2 = SFJ incompetence (indicator of Type 1, 3, or 1+2)
- EP N2→N3 = Perforator entry (Type 2A, 2B, 2C, or 3)
- RP patterns (N2→N1, N3→N2, N3→N1) = Reflux classification
- N1, N2, N3 = Anatomical compartments (deep, saphenous, tributary)
