================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "ModuleNotFoundError"
SOLUTION: Install missing packages
  pip install torch transformers peft datasets

PROBLEM: "CUDA out of memory"
SOLUTION: In Cell 2, reduce BATCH_SIZE:
  BATCH_SIZE = 2  (instead of 4)

PROBLEM: "Model download takes forever"
SOLUTION: First run downloads 7B model (~15GB). Subsequent runs use cache.

PROBLEM: "Training loss not decreasing"
SOLUTION:
  1. Verify data loaded (Cell 3)
  2. Check dataset created (Cell 7)
  3. Try more epochs: NUM_EPOCHS = 10

PROBLEM: "Training stops with error"
SOLUTION:
  1. Check error message carefully
  2. May need to restart kernel and re-run from Cell 1
  3. Check available VRAM: nvidia-smi

  BATCH_SIZE = 2  (instead of 4)
