Where Documents Come From
Looking at load_bm25_from_qdrant() (rag_engine.py, lines 116-151):


# This runs on app startup
def load_bm25_from_qdrant():
    client = _get_qdrant()
    chunks: list[str] = []
    
    # Scroll through ALL points in ligation_knowledgebase_db_v2
    while True:
        result, next_offset = client.scroll(
            collection_name=QDRANT_COLLECTION,
            limit=256,
            offset=offset,
            with_payload=True,  # ← Get the payload!
            with_vectors=False,
        )
        for point in result:
            text = (point.payload or {}).get("text", "")  # ← Extract text from payload
            if text:
                chunks.append(text)  # ← This is your "document"

Summary

Your Knowledge Base = Qdrant Collection
         ↓
Each entry in Qdrant = One "document" (text chunk in payload)
         ↓
Three ways to find relevant documents:
  1. Vector search (semantic) in Qdrant
  2. BM25 search (keyword) on extracted payloads
  3. Cross-encoder (neural reranking) on merged results
         ↓
Top 5 documents (text chunks) → Sent to LLM for ligation planning
The "documents" never leave Qdrant — we just extract their text payloads and search them different ways.
