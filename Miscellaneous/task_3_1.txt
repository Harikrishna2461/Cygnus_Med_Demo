Full Pipeline Plan
What the system does end-to-end
Raw ultrasound video → Stage 1 fascia detection → Stage 2 vein detection → Stage 3 vein tracking → per-frame annotations + temporal output

Stage 1 — Fascia Detection ✅ Done
Notebook 1 — 01_fascia_detection.ipynb

UNet-ResNet50 TF, 3-class segmentation (above / band / below fascia)
Val mIoU 99.1%, Fascia Dice 99.1%, Boundary F1 0.847
Polynomial curve fit extracts upper + lower fascia boundary lines
Checkpoint: output/fascia/checkpoints/unet_resnet50_tf_best.keras
Stage 2 — Vein Detection 🔄 Training now
Notebook 2 — 02_vein_detection.ipynb

UNet-ResNet50 TF, binary segmentation (background / vein)
2037 annotated frames from 3 videos (green contours extracted from Simple Annotated videos)
Loss: weighted Dice + CE with vein weight 15× to handle tiny structures
Output per frame: binary vein mask + vein centroids
Stage 3 — Vein Tracking ⏳ Not started
Notebook 3 — 03_vein_tracking.ipynb

Input: sequence of vein masks from Stage 2
Approach: centroid-based IoU matching with Hungarian algorithm
Handles: appearance, disappearance, probe motion, vein deformation
Output: vein IDs consistent across frames (same vein = same ID), trajectories
