Two noted gaps (not errors, future enhancements)
SPJ as Type 1b EP: Literature (Gianesini, Delfrate) recognizes SPJ as a valid N1→N2 entry point. If a user marks EP N1→N2 at posY≈0.50 posterior (SPJ zone), it should also be a valid Type 1 trigger — this already works in your code since it checks clip type not position.

Type 6 secondary variant: Delfrate describes N1→N3→competent N2→N1 (N2 drains without refluxing) — your code would classify this as Type 4. It's rare and clinically distinct, documented as an acceptable limitation.
